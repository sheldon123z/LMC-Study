# 项目文件说明

## 1. `function_calling.py`
该文件是一个框架构思，尚未完成代码实现。它旨在区分大模型的调用和基础的 `action` 与 `observation` 实现，作为未来开发的基础框架。

## 2. `registry_object.py`
该文件使用面向对象编程（OOP）理念重新设计了 `grid2op` 的环境与观察注册机制。它的作用是将 `environment` 实例和 `observation` 实例在主程序及其他函数中进行传递，并新增了 `observation` 的注册，与原版有所不同。

## 3. `static_properties.py`
该文件用于获取 `grid2op` 中发电机和存储单元的固有属性。未来在模型调用工具时，该文件可用于判定相关指令的合法性。

## 4. `test_oop.ipynb`
该 Jupyter Notebook 文件用于测试 `action` 或 `observation` 的函数实现。它更新了原 demo 环境的创建与注册程序，并修改了环境的 `parameters`，使得一次 `action` 可以修改 3 条电力线或发电机（默认限制为 1）。

## 5. `tool_impl_list.py`
该文件用于实际操作 `grid2op` 的程序。目前已完成了 `line_set_bus_impl` 和 `line_change_bus_impl` 函数的实现，并完成了相应的测试。

## 6. 其他
在原get_logger中增添了监测logs文件夹，若不存在则自动创建的功能。
